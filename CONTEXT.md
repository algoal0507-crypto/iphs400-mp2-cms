# CONTEXT.md glossary

Filled in from the `/grill-with-docs` session, 2026-09-28. See `notes/client-brief.md`
and `notes/restaurant-research.md` for the sourcing and reasoning behind each decision.

| Term | Meaning in this project |
|---|---|
| **La Once Mil** | The site's display name — the restaurant's own verified branding. Supersedes the earlier "Tacos La Oncemil" spelling used before this session, which was not an intentional name choice. |
| **Flagship location** | The one restaurant location this project models: Monte Everest 780, Lomas de Chapultepec, Mexico City — the Michelin-starred address. The Roma Norte location is out of scope and must never appear on the site. **Madrid (scope change, 2026-10-13):** Madrid appears only as company *News* (the opening post, with its sources). It is not a visiting location: Home's visiting information, the Menu, and Our Story stay on this Mexico City address. |
| **Demo Manager** | The seeded **admin** account for grading. Fictional — does not represent the real owner (César de la Parra) or any real staff. Can create/edit/delete Pages, manage users, and publish. |
| **Demo Editor** | The seeded **editor** account for grading. Fictional. Can create and edit **News** drafts only — cannot publish, cannot reach Pages, cannot manage users. |
| **Pages** | The site's "Pages" capability — same fields and admin-only create/read/update/delete operations as News/Posts (title, slug, Markdown body, status, author, timestamps), plus appearing in public navigation once published. Home, Menu, and Our Story are La Once Mil's seeded starting content (`scripts/seed_demo.py`), not a fixed limit — the Manager can add or remove Pages beyond them. Corrected 2026-09-29: an earlier decision called these "fixed, not freely creatable," which conflicted with the MP2 rubric/manual's "Pages: same operations as posts" requirement (see spec #1). |
| **News** | The site's "Posts" capability — draft/published announcements with title, slug, Markdown body, author, timestamps. Editor drafts; admin publishes. |
| **Publish** | The admin-only action that marks a draft (News post or a permanent page edit) as published **in the local CMS**. The editor role cannot perform this action under any content type. Publishing is not the same as the public site updating — the GitHub Pages site only reflects the change after `cms publish` exports to `site/` and that export is deployed. |
| **Navigation reachability** | Every published page, including Home, must be reachable by clicking through the public site's navigation — no published page is an orphan with no link pointing to it. |
| **Visiting information** | Verified address, hours, a directions link, and a prominent Call button — lives entirely on Home. *The Call button is pending: no verified phone number exists in the research sources, so none is shown (removed 2026-09-29) until the owner supplies one.* There is no separate Visit Us page. |
| **Menu (page)** | One ordinary Markdown permanent page listing dish names and descriptions. No prices (no verified peso pricing exists) and no structured menu/pricing database — deliberately out of scope. |
| **Placeholder image** | A clearly labeled stand-in image (e.g. `[PLACEHOLDER: storefront photo]`) used until a real, rights-cleared photo is supplied. Tracked in `notes/client-brief.md`'s image tracker. Never substituted with AI-generated or stock images. Since 2026-10-13 Home, Menu, and Our Story show three author-supplied photos (a `[PHOTO: key]` line in the page's Markdown); where each came from, and that permission is **not recorded**, is stated in `assets/images/CREDITS.md`. Any other page still uses a placeholder. |
| **Michelin item** | A real, dated news item seed content may include: Michelin announced La Once Mil as a new one-star restaurant in its Mexico selection on May 20, 2026. It is worded "its first Michelin star", never "the first taquería ever". Since 2026-10-13 the seed has two real items (this one and the **Madrid opening**, from the official announcement of September 14, 2026). A post's date in the News list is when it was published on this site; the date of the event is in its text, with a source link. Any other seeded News content is invented sample content and must be clearly labeled as demo. |
